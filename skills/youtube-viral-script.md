# YouTube Viral Script Generator

## When to use
When the user asks to write a YouTube script, needs a viral script structure, wants AI-assisted scripting workflows, or asks for script writing frameworks. Works in ANY language — detect the user's language from their message and output in that same language.

## Core Principles (from Tube Sensei + Aftab Khan)

### 1. PACKAGING COMES FIRST (NOT the script)
Script writing starts with packaging, not the intro:
- **Idea**: Topic must be strong. Weak idea = dead video regardless of script quality.
- **Title**: Sets audience expectation. If expectation ≠ reality → video fails.
- **Thumbnail**: Visual expectation. Must match actual video content.
- **Psychology**: Every professional scriptwriter thinks about packaging before writing a single word. Audience decides in 2-3 seconds whether to stay based on packaging.

### 2. INTRO = CLICK CONFIRMATION + CURIOSITY GAP (3-6 seconds)
The intro must accomplish TWO things:
- **Click Confirmation**: Assure viewer the video delivers what packaging promised. Show/tell within first 3 seconds.
- **Curiosity Gap**: Give a teaser of what's coming. Open a loop they need closed.

**5 Methods to Create Curiosity Gap:**
1. **FOMO** — Make audience feel they'll miss something valuable if they leave
2. **Relativity** — Present a situation the audience can personally relate to
3. **Fear** — Show personal loss or risk to the audience
4. **Question** — Ask something unknown to the audience
5. **Pattern Interruption** — Challenge a commonly held belief

### 3. RESEARCH = SHOCK VALUE
Shock value = the distance between YOUR knowledge and AUDIENCE knowledge. Bigger gap = better retention.

**3 Ways to Increase Shock Value:**
- **Consuming**: Diverse sources (books, articles, courses, multiple platforms) — things normal audience doesn't access
- **Doing**: Personal experience. Challenge-based research. No one else has YOUR experience.
- **Analyzing**: Study patterns from other creators' videos and your own past content. Find what works and package it.

### 4. BODY = FRAMING + PACING + TRANSITION

**Framing** (Storytelling Structure):
- Context setting → Details → Challenge introduced → Climax/Resolution
- Use "Retention Dance": Best/unique info → Normal/known info → Unique/special info → Normal → repeat
- This prevents the audience from deciding to leave. Don't put all best info at the start.

**Pacing** (Emotion Control):
- Script must go up and down — not flat. Use pattern interruption.
- Insert unexpected elements (memes, examples, jokes, visuals) to break monotony.
- Monotonous tone = bored audience.

**Transition** (Between Points):
- Human attention span is ~8 seconds. Storytelling extends to ~3 minutes.
- Every ~3 minutes, make audience realize "what I expected WON'T happen" → give new reason to stay.
- Easily shift from point A to point B.

### 5. OUTRO = DULL LOOP TRAP
- **Summarize** key points of the video (viewers came with expectations, leave with more value)
- **Create Need** for the next video — build curiosity about what's coming
- NOT just "like and subscribe." Give a genuine reason to return.

## AI-ASSISTED SCRIPTING SYSTEM (from Aftab Khan)

### Phase 1: Build Your Training Dataset
1. Find 5 top creators in your niche (same language as your target content)
2. Collect transcripts:
   - **YouTube long-form**: Copy transcript from description/show transcript
   - **YouTube Shorts**: Use desktop URL (replace `shorts/` with `watch/`) → get transcript
   - **Instagram Reels**: Download video → transcribe with tool
3. Quantity: 50-100 short-form scripts, 20+ long-form scripts
4. **Structure the raw transcripts**: Clean and format each with clear markers:
   - Hook | Build-up | Content/Value | Re-Hook | CTA
   - Remove timestamps, clean filler words
   - This is the viral training dataset

### Phase 2: Define Your System
Set up in Claude Projects (or equivalent AI with knowledge base):
- **Custom Instructions**: Define goal, content format, target audience PRECISELY
- **Goal**: What result should viewer get? (e.g., "Learn to script viral videos")
- **Format**: Long-form / Shorts / Documentary
- **Target Audience**: Be specific. NOT "everyone." Define exact persona.
- **Output Structure**: How scripts should be formatted (hook → buildup → content → CTA)

### Phase 3: Script Generation Workflow
1. **Generate Ideas**: Ask AI to analyze top creators' titles, find research gaps (what they missed)
2. **Create Outline**: NOT a full script yet. Get structured outline with all points.
3. **Verify Facts**: Manually check dates, names, events. Enable web search for current topics.
4. **Write Script**: Paste verified outline → ask AI to write full script in specific creator's tone.
5. **Refine**: Read line-by-line. Use "Meta-prompting" (ask GPT-4: "Identify weak sections, confusing parts, and missing elements").
6. **Update System**: Add discovered weaknesses to custom instructions for next time.

### Phase 4: Continuous Improvement
- First draft = 70-80% quality. Edit yourself to reach 95%+.
- Track what you change → update custom instructions → system gets better.
- By 10th iteration, AI delivers 90-95% production-ready scripts.

- **Tech/Geopolitics/Current Events**: Enable web search. Use sources with citations.

## Script Generation Instructions

When asked to write a script, follow these steps:

1. **Detect the user's language** — output in the same language they wrote in (Hindi, English, Bengali, etc.)

2. **Ask clarifying questions if needed**:
   - Topic/niche?
   - Target audience?
   - Long-form or short-form?
   - Any specific tone or reference creator?

3. **Generate the script** using the framework above:
   - Strong packaging concept (title + thumbnail idea)
   - Hook with click confirmation + curiosity gap
   - Body with retention dance (best→normal→unique→normal)
   - Transitions every ~3 minutes
   - Pattern interruptions for pacing
   - Outro with summary + next-video tease

4. **Include metadata** with each script:
   - Suggested title
   - Thumbnail concept
   - Target audience
   - Estimated duration
   - Key retention hooks marked

## Golden Rules
- Content is for the VIEWER, not for you. Always answer: "Why would the viewer watch this?"
- Better input = better output. Garbage in, garbage out.
- Idea + Angle > Script structure. A strong script starts with a strong angle.
- Don't put all best info at the start — spread it out with the retention dance.
- Verify facts. One wrong fact destroys credibility.
